# Chrome Web Store listing draft

## Name

SUHMAN Crusher Selection Calculator

## Short description

Estimate a mobile crusher and screen configuration from material, feed size and target t/h.

## Detailed description

SUHMAN Crusher Selection Calculator is a free planning tool for quarry, mining and construction-waste projects.

Enter the material, maximum feed size, target finished output, main product and mobility preference. The extension returns a starting crushing line, models to compare, a matching solution and similar SUHMAN project references.

Features:

- Estimate a primary and secondary crushing configuration
- Compare mobile jaw, cone, impact and screening models
- Check screening capacity and modular alternatives
- Open the full SUHMAN calculator for more detail
- Works locally in the browser

The extension does not collect personal data, does not read the current page and does not load remote code.

Results are planning estimates. Final configuration is confirmed by an engineer.
